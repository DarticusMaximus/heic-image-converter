Sources of truth, named once so each verdict below is checkable:

- **Manifest:** `src-tauri/vendor/heif-bundles/manifest.json` (release
  `26.10.1`, crate `heif-rs` `26.10.3`), read with `python3`.
- **Published digest:** GitHub's per-asset `digest` field on the pinned release,
  read with `gh release view 26.10.1 --repo vegidio/binaries-heif --json assets`.
  The release page is
  `https://github.com/vegidio/binaries-heif/releases/tag/26.10.1`, published
  `2026-10-24T09:53:23Z`.
- **Committed bytes:** the four archives under
  `src-tauri/vendor/heif-bundles/`, compared to the downloads with `cmp`.

**What the release does and does not publish.** It publishes a digest for each
archive. It publishes **no digest for the static library inside the archive**.
So the `sha256` verdict has a published digest to compare against, and the
`lib_sha256` verdict compares the extracted library against the manifest's
`lib_sha256` only; the archive digest above it is the published anchor that made
the extraction trustworthy in the first place.
